# 뽑기판 재고 서버 설정 (구글 시트 + Apps Script)

뽑을 때마다 시트의 남은 수량이 1씩 줄고, 휴대폰 화면에 "남음 ○개"가 표시됩니다. 시트를 열어 두면 부스 현황판이 됩니다.

## 1. 스프레드시트 만들기
1. https://sheets.new 에서 새 스프레드시트를 만듭니다. 이름은 "브리티 뽑기판 재고" 정도.
2. 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.

## 2. 스크립트 붙여 넣기
1. 편집기에 있는 내용을 모두 지우고, 이 저장소의 `tools/draw-backend.gs` 내용을 그대로 붙여 넣습니다.
2. 저장(디스크 아이콘)합니다.
3. 상단 함수 선택 칸에서 **setup** 을 고르고 **실행** 을 누릅니다.
   - 처음 한 번 권한 확인 창이 뜹니다. 계정 선택 → "고급" → "…(안전하지 않음)으로 이동" → 허용.
   - 실행이 끝나면 시트에 **재고**, **기록** 탭이 생기고 5등급 수량이 들어가 있습니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. 설정:
   - 설명: 뽑기판
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 권한 허용 → 나오는 **웹 앱 URL**(https://script.google.com/macros/s/…/exec)을 복사합니다.
5. 그 URL을 저에게 보내 주세요. `play.html`의 `DRAW_API`에 넣어 올립니다.

## 4. 운영
- **재고** 탭의 D열(남은 수량)이 실시간 현황입니다. 수량을 고치려면 C열과 D열 숫자를 직접 바꾸면 됩니다.
- **기록** 탭에 뽑은 시각·등급·기기ID가 한 줄씩 쌓입니다.
- 한 등급이 0이 되면 그 등급은 더 이상 나오지 않고, 전부 0이면 "선물 마감"이 뜹니다.
- 인터넷이 끊기면 휴대폰 안에서만 뽑는 방식으로 자동 전환됩니다(시트에는 안 남음).

## 5. 수정 후 다시 배포할 때
스크립트를 고쳤다면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. URL은 그대로입니다.
